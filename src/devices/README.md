# 部品ドライバ

`devices.cpp`の`kDevices`が、このプロジェクトで扱う部品の唯一の定義になる。
ID・表示名・補足・単位・種別・許される操作・ピン番号・極性・変化の判定幅をここにまとめ、
`GET /api/devices`で配る。操作UIも、将来のBlocklyのツールボックスも、この配信結果から組み立てる。

部品を増やすときは、この表に1行足す。センサなら読み取り関数も渡す。

出力の変更は必ず`setDeviceOutput()`を通す。手動操作でもAST実行でも同じ経路にしておくことで、
変化の発生元にかかわらず`takeChangedDevices()`が拾い、同じ形でクライアントへ届く。

起動時は一度すべてONにして点灯・鳴動を確かめた後、必ずOFFにそろえる。
状態の正をESP32に置くため、起点の状態が決まっていないと最初の配信が実機とずれる。

センサの読み取り本体は`sensors.cpp`に置く。I2Cの初期化と各センサ固有の手順はここに閉じ込め、
`devices.cpp`へは`float`を返す読み取り関数だけを見せる。表の`read`にそのまま渡せる形にしておくことで、
センサを増やしてもカタログ側の書き方は変わらない。

設計の理由は[adr/0001](../../adr/0001-device-state-and-control.md)を参照。
距離センサを待たずに読む理由は[adr/0002](../../adr/0002-nonblocking-distance-sampling.md)にある。
