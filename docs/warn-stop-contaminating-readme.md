# For other contributers

- Don't contaminate README.md.
- These things below must not be written in README.md.
  - The description of the behavior that can be changed in a short period of time.
    (e.g.: "The system *currently* works in local.") 
  - The description of highly specialized logical behaviors.
    (e.g.: A detailed description of AST node handling)

- README.md always should provide simple, readable, and essential descriptions to use this system.


## Note

Please refer to commit "1c14b8c0" for specific examples and revisions regarding the above content.
