## 中断していたJSON不具合の対応

ArduinoJson 7.4.3で、一時的な`const RunSnapshot &`の`error.blockId`配列を直接代入すると、
JSONが文字列をコピーせず参照を保持することをPC版Unityで再現しました。
修正前は17件中1件失敗し、期待値`divide`が元配列の変更後に`xxxxxx`になりました。

- [state_json.h](../src/runtime/state_json.h)で`JsonString(..., false)`を使い、`blockId`を明示コピーします。
- [program_api.cpp](../src/api/program_api.cpp)のHTTP応答とSSEに同じ状態JSON生成処理を接続し、重複を除去しました。
- 検証エラー応答も共通化し、診断文字列のコピーを明示しました。
- 元データ変更・スコープ終了後のJSONシリアライズ、エラーなし状態、検証エラーの形式を回帰テストに追加しました。

この修正が実際の非同期HTTP応答でも問題を解消するかは、次の実機検証で確認します。
