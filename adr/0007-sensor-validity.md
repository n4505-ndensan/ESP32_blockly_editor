# ADR 0007: センサ異常を数値0と区別する

- ステータス: 採用
- 日付: 2026-09-15
- ADR 0001のセンサstate形式、ADR 0002の失敗時に0を返す決定を一部置き換える。

## 決定

センサは値・正常取得時刻・状態を保持する。外部には`value: number | null`と
`status: ok | unavailable | stale`を配信する。未取得・通信失敗・無効な測距結果はunavailable、
正常取得から1秒経過した値はstaleとし、無効な状態ではvalueをnullにする。

ASTが無効なセンサを実際に参照した場合は、そのブロックでエラーにして全出力をOFFにする。
使用していないセンサや短絡評価で参照しないセンサの異常では停止しない。

AMG8833は初期化結果と各I2C読み取りの成否を確認し、64画素の最高温度を計算する。
VL53L1Xは100ms間隔の連続測定を維持し、測定待ちは行わない。通信結果に加え、
RangeValid・RangeValidMinRangeClipped・RangeValidNoWrapCheckFailだけを有効な測距結果とする。
正常な新規測定の合間は前回値を保持する。初期化失敗からの復帰は再起動で行う。

最新の正常値はepsilon未満の変化でも保存する。epsilonは前回配信値との比較にのみ使い、
有効性の変化は値の差にかかわらず通知する。I2Cのタイムアウトは10msとする。

## 理由

失敗時の0を「距離がしきい値未満」などの条件に使うと、測定できていないのに条件が成立してしまう。
また、配信を抑えるために制御用の値まで丸めると、ブロックが最新の測定値を参照できない。
